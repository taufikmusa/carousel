# Pustaka copywriting Taufik
Mula disimpan 18 Nov 2026. Satu fail `.md` setiap post: `YYYY-MM-DD-slug.md`, dengan front-matter di atas.
Cari ikut kata kunci dalam `INDEX.md`. Bila Taufik minta "ada copy pasal X?": cari, cadang 2-3 tajuk + ringkasan, dia pilih.
Peraturan:
- `data_bertarikh: ya` = ada harga/graf/tarikh. Bila dicadangkan semula, ingatkan Taufik KEMAS KINI angka dahulu.
- `petikan_disahkan: tidak` = petikan guru/podcast belum disahkan Taufik. Ingatkan sebelum guna.
- Simpan teks ASAL Taufik (jangan ringkaskan). Kemas kini INDEX.md setiap kali tambah fail.
